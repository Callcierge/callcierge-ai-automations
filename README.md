# AI Lead Gen Workflows

3 automated systems for outbound prospecting, inbound email handling, and end-to-end SDR — built on n8n.

## What's Inside

- Outbound Lead Machine — scrapes leads, finds emails, sends a 4-step email sequence, detects replies
- Inbound Email Agent — reads and classifies emails, replies with AI, books meetings, updates your CRM
- End-to-End SDR — combines both into one connected pipeline

## How to Use

1. Download the JSON file above
2. Import it into your n8n instance (Import from file)
3. Connect your accounts (Gmail, OpenAI, Airtable, etc.)
4. Follow the full setup guide: [link to your doc or bio]

## Tools Required

n8n, OpenAI API, Gmail, Google Sheets, Google Calendar, Apify, Prospeo, Hunter, Perplexity, Airtable, Slack
